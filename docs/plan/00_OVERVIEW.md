## 공통 원칙

- 단계마다 Cursor가 멈추고 보고 → 확인 후 다음 단계.
- 커밋은 단계 끝에 파일 이름을 지정해서. `git add .` 금지. force push, rebase, reset은 요청 시에만.
- 실제 스케줄 PDF, 크루 이름·사번은 저장소에 넣지 않는다. 테스트는 익명 샘플(편명 `XX000`, 사번 `0000000`).
- 모든 데이터는 기기 안에만 저장. 서버 전송 없음.
- 공개 문구(스토어, 랜딩)에는 항공사 이름·코드를 쓰지 않는다.
- 의학적 판단처럼 보이는 표현 금지.
- 시간은 내부 UTC, 화면에서만 현지·홈베이스 시간대로 표시.
