# 2단계: 스케줄 PDF 해석기, 공유하기로 받기

상태: ⬜ 미착수

## 확인된 양식 (회사 월간 스케줄 PDF)
- 텍스트형 PDF(OCR 불필요), 2쪽 내외.
- 맨 위 줄: 본인 이름 | 사번 | 기종 | 직급, 월간 합계(FLY, TVL, DO, RESERVE).
- 구간 블록: Flight/Activity, From, STD, To, STA, A/C. STD는 편명 줄 바로 위 줄에 찍힌다.
- STD·STA는 각 공항 현지 시각 → 공항 코드로 IANA 시간대를 붙여 UTC로 변환.
- 구간마다 크루 전원 줄(직급, FLY/TVL, 벙크 코드 P1/P2/F1/F2, 사번, 이름, 비고).
- 픽업·쇼업 시각은 없음(4단계에서 입력).
- 참고: 별도 '비행 기록(Flight Log Report)' PDF는 지난 비행 기록이라 메인 입력 아님(나중에 회고용).

## 할 일
- [ ] 기기 안 PDF 텍스트 추출
- [ ] 양식 해석기 인터페이스(양식마다 하나), 첫 해석기 = 위 양식
- [ ] 맨 위 줄 사번으로 **본인 줄만** 남기고 다른 크루 정보는 즉시 버림(저장·표시·로그 금지)
- [ ] 본인 근무 FLY/TVL, 벙크 코드 추출
- [ ] 공항 코드 → 시간대 표 확장, 모르는 공항은 사용자에게 시간대 선택 요청
- [ ] 다른 앱 '공유하기 / 다른 앱으로 열기'로 PDF 받기(Android 인텐트, iOS 문서 열기)
- [ ] 모르는 양식 → 양식 제보 흐름
- [ ] 테스트는 이름 삭제·편명 XX000·사번 0000000으로 바꾼 가짜 텍스트
